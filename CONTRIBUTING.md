# Contributing / Mitwirken

**[English](#english) · [Deutsch](#deutsch)**

<a name="english"></a>
## English

Thank you for your interest in PlatinVault!

- **Issues are welcome:** bug reports, questions and ideas go to
  [GitHub Issues](https://github.com/sushiflux/PlatinVault/issues). For a bug, please name the platform (Windows program, Unraid,
  Linux/Docker, NAS), the version shown in the app and what you did, what you expected and what happened instead.
- **Pull requests:** please open an issue first for anything bigger than a small fix, so we can agree on the approach. The README
  section "Development" shows the layout, how to start it and how to run the tests. Code comments are in English, user-visible texts
  in German and English (server texts in `ServerTexts`, UI texts through i18next in `frontend/src/i18n/`).
- **Licence of contributions:** PlatinVault is licensed under the GNU Affero General Public License v3, that version only
  (AGPL-3.0-only, see [`LICENSE`](LICENSE)). By submitting a contribution you agree that it is licensed under AGPL-3.0-only as well.
- **Security problems:** please do not open a public issue for a vulnerability; use GitHub's private vulnerability reporting
  ("Security" tab → "Report a vulnerability") if it is enabled for this repository.

<a name="deutsch"></a>
## Deutsch

Danke für dein Interesse an PlatinVault!

- **Issues sind willkommen:** Fehlerberichte, Fragen und Ideen gehören in die
  [GitHub-Issues](https://github.com/sushiflux/PlatinVault/issues). Nenne bei einem Fehler bitte die Plattform (Windows-Programm,
  Unraid, Linux/Docker, NAS), die in der App angezeigte Version und was du getan hast, was du erwartet hast und was stattdessen passiert ist.
- **Pull Requests:** öffne bitte für alles, was größer als eine kleine Korrektur ist, zuerst ein Issue, damit wir uns über den Weg
  einigen. Der Abschnitt „Entwicklung“ der README zeigt den Aufbau, wie man es startet und die Tests ausführt. Code-Kommentare sind
  auf Englisch, sichtbare Texte auf Deutsch und Englisch (Servertexte in `ServerTexts`, Oberflächentexte über i18next in
  `frontend/src/i18n/`).
- **Lizenz von Beiträgen:** PlatinVault steht unter der GNU Affero General Public License v3, nur diese Version (AGPL-3.0-only,
  siehe [`LICENSE`](LICENSE)). Mit dem Einreichen eines Beitrags stimmst du zu, dass er ebenfalls unter AGPL-3.0-only steht.
- **Sicherheitslücken:** bitte nicht als öffentliches Issue melden; nutze die private Meldung von GitHub (Reiter „Security“ →
  „Report a vulnerability“), sofern sie für dieses Repository eingeschaltet ist.
